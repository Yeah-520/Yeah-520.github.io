如何搭建一个零依赖的静态个人网站

2025 年 1 月 12 日 · 约 5 分钟阅读
HTML CSS JavaScript

很多人以为搭建一个现代网站必须借助 React、Vue 或者构建工具，但实际上，对于个人主页这样以内容为主的站点， 纯静态的 HTML + CSS + 原生 JavaScript 往往是最轻量、最可靠的选择。 没有依赖要安装，没有构建要等待，文件放到任何静态托管（如 GitHub Pages）上就能直接访问。

为什么选择零依赖

零依赖方案有几个显而易见的好处：

  • 轻量快速：没有框架运行时与打包产物，首屏加载极快。
  • 易于维护：代码结构清晰直接，任何浏览器都能离线打开调试。
  • 长期稳定：不依赖第三方 CDN 或版本升级，多年后依然可运行。

用 CSS 变量统一设计

视觉一致性是「简约现代」的关键。把颜色、间距、圆角、阴影收敛到 :root 中的 CSS 变量， 后续无论是微调风格还是实现暗色模式，都只需改一处。 

:root {
  --color-bg: #ffffff;
  --color-text: #1a1d21;
  --color-accent: #2563eb;
  --radius-md: 12px;
  --space-6: 32px;
}

[data-theme="dark"] {
  --color-bg: #0e1116;
  --color-text: #e7eaef;
  --color-accent: #5b8cff;
}

通过给 <html> 切换 data-theme 属性，暗色模式就完成了大半。

用少量脚本增强交互

原生 JavaScript 足以覆盖个人网站的全部交互需求：

  1. 移动端汉堡菜单的展开与收起；
  2. 主题切换，并用 localStorage 记住用户偏好；
  3. 使用 IntersectionObserver 实现滚动渐入动画。
好的设计是尽可能少的设计 —— 用最少的代码，达成清晰、克制的体验。

小结

零依赖并不等于简陋。语义化标签、CSS 变量、无障碍细节与克制的动效，同样能打造出专业且耐看的网站。 希望这篇文章能给你一些启发，也欢迎去 作品集 看看这个网站的实际效果。
