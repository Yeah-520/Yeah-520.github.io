# 注意事项

# primary key 和 unique 区别

| 区别         | primary key | unique                 |
| ---------- | ----------- | ---------------------- |
| 中文         | 主键          | 唯一约束                   |
| 作用         | 唯一标识一行数据    | 保证字段值唯一                |
| 数量         | 一张表只能有一个    | 可以有多个                  |
| NULL       | 不允许 NULL    | 允许 NULL（MySQL中可多个NULL） |
| 是否自动创建索引   | 是           | 是                      |
| 是否可以作为外键引用 | 通常作为目标      | 也可以                    |
| 是否必须存在     | 建议必须有       | 可选                     |

# auto_increment

1. **一张表最多只能有 1 个自增列**
2. **自增列必须定义为索引，且必须是该索引的第一列（最左列）**（通常是主键）
3. **自增一般配合无符号 `unsigned` 使用，避免负数**
4. 自增初始值默认从 1 开始；可在建表 / 修改时指定起始值

```mysql
alter table student auto_increment=100;
```

5. 删除数据**不会自动回退自增计数器**

> delete 删除行，自增号继续递增；truncate 会重置自增为 1

6. 自增字段插入 null，自动分配下一个编号

```mysql
insert into student(id,name) values(null,'张三');
```

7. 外键关联时：**主表自增字段和从表外键字段类型、unsigned 必须一致**，否则外键报错
8. 自增列必须是数值类型（int /bigint），varchar 不能加 auto_increment
9. 联合主键 / 联合索引场景：**只有索引的最左（第一）列可以设 auto_increment**，例如 `primary key(a,b)` 中只有 a 可以自增

# where name is NULL

判断字段是否为 NULL，必须使用 `is null` / `is not null`，**不能**用 `= null` 或 `!= null`。

原因：NULL 表示「未知」，任何值与 NULL 的等值比较，结果都是 NULL（既非 true 也非 false），永远过滤不到数据。

```mysql
-- 正确写法
select * from emp where name is null;
select * from emp where name is not null;

-- 错误写法（查不到任何结果）
select * from emp where name = null;
```

# where 不能使用聚合函数

SQL查询中，`WHERE` 子句在数据分组和聚合之前执行，因此无法使用 `SUM()`、`COUNT()` 等聚合函数进行条件过滤。若需要对聚合后的结果进行筛选，应使用 `HAVING` 子句。
