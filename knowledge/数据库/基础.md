# MySQL基础

## 一、MySQL概述

### 启动与连接

- Windows：`services.msc` 管理mysql服务
- 客户端连接：`mysql -u用户名 -p密码`
  - `-u` 指定用户名，`-p` 指定密码（也可只写 `-p` 后回车交互输入，避免密码暴露在命令行）
  - `-h 主机地址`（默认 `localhost`），`-P 端口`（默认 `3306`，大写 P）
  - 示例：`mysql -h127.0.0.1 -P3306 -uroot -p123456`

### 关系型数据库

建立在关系模型基础上，由多张相互连接的二维表组成的数据库。

- 数据库服务器中可以创建多个数据库，一个数据库中可以创建多张表。

## 二、SQL

### 1. SQL通用语法

- MySQL的SQL语句**不区分大小写**。
- 单行注释：`-- 注释内容` 或 `#注释内容`；多行注释：`/* 注释内容 */`

### 2. SQL分类

| 分类  | 全称                         | 说明                          |
| --- | -------------------------- | --------------------------- |
| DDL | Data Definition Language   | 数据定义语言，用来定义数据库对象(数据库，表，字段)  |
| DML | Data Manipulation Language | 数据操作语言，用来对数据库表中的数据进行增删改     |
| DQL | Data Query Language        | 数据查询语言，用来查询数据库中表的记录         |
| DCL | Data Control Language      | 数据控制语言，用来创建数据库用户，控制数据库的访问权限 |

### DDL（数据定义语言）

#### 数据库操作

```mysql
-- 查询所有数据库
show databases;
-- 查询当前数据库
select database();

-- 创建数据库 if not exists 避免出现重复创建时报错
create database [if not exists] 数据库名 [default charset 字符集 collate 排序规则];

-- 删除数据库 if exists 避免出现重复删除时报错
drop database [if exists] 数据库名;

-- 使用数据库
use 数据库名;
```

#### 表操作

```mysql
-- 查询当前数据库所有表
show tables;
-- 查询指定表的建表语句
show create table 表名;

-- 创建表
create table 表名(
    字段1 字段类型 [comment 字段注释],
    字段2 字段类型 [comment 字段注释],
    ...
    字段n 字段类型 [comment 字段注释]
)[comment 表注释];
```

示例：

```mysql
create table tb_user(
    id int comment '编号',
    name varchar(50) comment '姓名',
    age int comment '年龄',
    gender char(1) comment '性别'
) comment '用户表';
```

##### 数据类型

1. **数值类型**

| 类型            | 有符号范围                                      | 无符号范围（unsigned）          |
| ------------- | ------------------------------------------ | ------------------------ |
| TINYINT       | -128 ~ 127                                 | 0 ~ 255                  |
| SMALLINT      | -32768 ~ 32767                             | 0 ~ 65535                |
| MEDIUMINT     | -8388608 ~ 8388607                         | 0 ~ 16777215             |
| INT / INTEGER | -2147483648 ~ 2147483647                   | 0 ~ 4294967295           |
| BIGINT        | -9223372036854775808 ~ 9223372036854775807 | 0 ~ 18446744073709551615 |
| FLOAT         |                                            |                          |
| DOUBLE        |                                            |                          |
| DECIMAL(M,D)  | 依赖M（精度）和D（标度）的值，                           | M：总位数，D：小数位数             |

> 补充：`float` 单精度、`double` 双精度，浮点数存在精度损失，不适合精确计算；`decimal(M,D)` 是定点数，精确存储，金额等场景推荐使用

> 举例：`age tinyint unsigned` 年龄一般不会超过四位，不会为负数

2. **字符串类型**

| 类型           | 大小                 | 描述                   |
| ------------ | ------------------ | -------------------- |
| CHAR(NUM)    | 0~255 bytes        | 定长字符串                |
| VARCHAR(NUM) | 0~65535 bytes      | 变长字符串，最大长度受行大小和字符集影响 |
| TINYBLOB     | 0~255 bytes        | 不超过255个字符的二进制数据      |
| TINYTEXT     | 0~255 bytes        | 短文本字符串               |
| BLOB         | 0~65535 bytes      | 二进制形式的长文本数据          |
| TEXT         | 0~65535 bytes      | 长文本数据                |
| MEDIUMBLOB   | 0~16777215 bytes   | 二进制形式的中等长度文本数据       |
| MEDIUMTEXT   | 0~16777215 bytes   | 中等长度文本数据             |
| LONGBLOB     | 0~4294967295 bytes | 二进制形式的极大文本数据         |
| LONGTEXT     | 0~4294967295 bytes | 极大文本数据               |


> char(num)：定长字符串，固定占用num个字符空间（场景：手机号、身份证、固定编号）
> varchar(num)：变长字符串，实际字符长度 + 1/2 字节长度前缀（场景：用户名、地址）

| 对比项   | char(n)                        | varchar(n)                    |
| ----- | ------------------------------ | ----------------------------- |
| 存储方式 | 定长，不足 n 用空格补齐                   | 变长，按实际长度存储                    |
| 额外开销 | 无                              | 额外 1~2 字节记录长度                   |
| 最大长度 | 255 字符                         | 65535 字节（受行大小与字符集限制）         |
| 尾部空格 | 读取时自动去除                        | 保留                            |
| 性能   | 略好（长度固定）                       | 略差，但更省空间                      |
| 适用场景 | 固定长度（手机号、身份证、MD5、性别）            | 长度可变（姓名、地址、简介、邮箱）             |

3. **日期时间类型**

| 类型        | 大小      | 描述                                                            |
| --------- | ------- | ------------------------------------------------------------- |
| YEAR      | 1 bytes | YYYY                                                          |
| DATE      | 3 bytes | YYYY-MM-DD                                                    |
| TIME      | 3 bytes | hh:mm:ss                                                      |
| DATETIME  | 8 bytes | YYYY-MM-DD hh:mm:ss                                           |
| TIMESTAMP | 4 bytes | YYYY-MM-DD hh:mm:ss 1970-01-01 00:00:01 到 2038-01-09 03:14:07 |


##### 修改表

```mysql
-- 添加字段
alter table 表名 add 字段名 类型 [comment 注释];

-- 修改字段类型
alter table 表名 modify 字段名 新数据类型;

-- 修改字段名和字段类型
alter table 表名 change 旧字段名 新字段名 类型 [comment 注释];

-- 删除字段
alter table 表名 drop 字段名;

-- 修改表名
alter table 表名 rename to 新表名;
```

示例：

```mysql
alter table emp add name varchar(20) comment '昵称';
alter table emp change name username varchar(30);
alter table emp rename to employee;
```

##### 删除表

```mysql
-- 删除表
drop table [if exists] 表名;
-- 删除表，并重新创建该表（清空表内数据，保留表结构）
truncate table 表名;
```

### DML（数据操作语言）

#### 添加数据 insert

```mysql
-- 给指定字段添加数据
insert into 表名(字段1,字段2,...) values(值1,值2,...);

-- 给全部字段添加数据
insert into 表名 values(值1,值2,...);

-- 批量添加数据
insert into 表名(字段1,字段2,...) values(值1,值2,...),(值1,值2,...);
insert into 表名 values(值1,值2,...),(值1,值2,...);
```

#### 修改数据 update

```mysql
update 表名 set 字段名1 = 值1, 字段名2 = 值2,... [where 条件];
```

> <font color="red">注：不加where条件，会修改表中全部记录</font>

#### 删除数据 delete

```mysql
delete from 表名 [where 条件];
```

> <font color = "red">注意：不加where条件，会删除表中全部记录</font>

| 命令         | 分类  | 作用               | 能否回滚   | 是否保留表结构     | 自增计数器 |
| ---------- | --- | ---------------- | ------ | ----------- | ----- |
| `delete`   | DML | 删除指定行，可加 where    | 事务内可回滚 | 保留          | 不重置   |
| `truncate` | DDL | 清空整表数据           | 不可回滚   | 保留          | 重置为 1 |
| `drop`     | DDL | 删除整个表（含数据与结构）     | 不可回滚   | 不保留（表被删除）     | 不存在   |

### DQL（数据查询语言）

```mysql
select 字段列表 from 表名列表 [where 条件 group by 分组字段 having 分组后条件 order by 排序字段 limit 分页参数];
```

#### 基础查询

```mysql
-- 查询多个字段
select 字段1,字段2,字段3... from 表名;

-- 查询所有字段
select * from 表名;

-- 设置别名
select 字段1 [as 别名1], 字段2 [as 别名2] ... from 表名;

-- 去重
select distinct 字段列表 from 表名;
```

#### 条件查询 where

```mysql
-- 条件查询
select * from 表名 where 条件;
```

| 比较运算符               | 功能                     |
| ------------------- | ---------------------- |
| >                   | 大于                     |
| >=                  | 大于等于                   |
| <                   | 小于                     |
| <=                  | 小于等于                   |
| =                   | 等于                     |
| <> 或 !=             | 不等于                    |
| between ... and ... | 在某个范围之内(含最小、最大值)       |
| in(...)             | 在in之后的列表中的值，多选一        |
| like 占位符            | 模糊匹配(_匹配单个字符，%匹配任意个字符) |
| is null             | 是null                  |

| 逻辑运算符     | 功能  |
| --------- | --- |
| and 或 &&  | 并且  |
| or 或 \|\| | 或者  |
| not 或 !   | 非   |

示例：

```mysql
select * from emp where age=20;  
select * from emp where age<26;  
select * from emp where idcard is null;  
select * from emp where idcard is not null;  
select * from emp where age!=20;  
select * from emp where age>=23 and age<=28;  
select * from emp where age between 23 and 28;  
select * from emp where gender='女' and age<23;

select * from emp where age in (20,21,23);  
select * from emp where name like '___';  
select * from emp where idcard like '%6';
```

#### 聚合函数

将一列数据作为一个整体，进行纵向计算

| 函数        | 功能   |
| --------- | ---- |
| count(字段) | 统计数量 |
| max(字段)   | 最大值  |
| min(字段)   | 最小值  |
| avg(字段)   | 平均值  |
| sum(字段)   | 求和   |

>注意：`count(*)` 统计所有行数，包含NULL值；而`count(字段)`只统计该字段非NULL的行数。
>
> 三种 count 的区别：
> - `count(*)`：统计全部行（含 NULL），推荐写法
> - `count(1)`：等价于 `count(*)`，也是统计全部行
> - `count(字段)`：只统计该字段非 NULL 的行，字段有索引时更快

语法：

```mysql
select 聚合函数(字段) from 表名;
```

示例：

```mysql

select count(*) from emp;
select avg(age) from emp;  
select max(age) from emp;  
select sum(age) from emp where workaddress='北京';
```

#### 分组查询 group by

```mysql
select 字段列表 from 表名 [where 条件] group by 分组字段 [having 分组后条件];
```

- where：分组前进行过滤；having：分组后对结果进行过滤
- where不能对聚合函数进行判断，而having可以
- 执行顺序：where > group by > 聚合函数 > having

> 注意：分组之后，查询的字段一般为聚合函数和分组字段，查询其他字段无意义

示例：

```mysql
select gender,count(*) from emp group by gender;
select gender,avg(age) from emp group by gender;
select gender,avg(age) from emp where age<45 group by gender having avg(age)>30;
```

#### 排序查询 order by

```mysql
select 字段列表 from 表名 order by 字段1 [排序方式], 字段2 [排序方式];
```

- `asc`：升序（默认）
- `desc`：降序

> 注意：多字段排序：当第一个字段值相等时，才会按第二个字段排序

示例：

```mysql
select * from emp order by age asc;
select * from emp order by entrydate desc;
select * from emp order by age asc,entrydate desc;
```

#### 分页查询 limit

```mysql
select 字段列表 from 表名 limit 起始索引, 查询记录数;
```

- 起始索引从0开始，起始索引 = (查询页码 - 1) * 每页显示记录数
- 如果查询的是第一页数据，起始索引可以省略，简写为 limit 记录数

> 注意：limit是MySQL方言，不同数据库实现不同

示例：

```mysql
select * from emp limit 0,10; -- 查询第1页员工信息，每页10条记录
select * from emp limit 10,10; -- 查询第2页员工信息，每页10条记录
```

> DQL执行顺序：
```
from
↓
join
↓
on
↓
where
↓
group by
↓
having
↓
select
↓
order by
↓
limit
```

### DCL（数据控制语言）

#### 管理用户

```mysql
-- 查询用户
select * from mysql.user;

-- 创建用户
create user '用户名'@'主机名' identified by '密码';

-- 修改用户密码
alter user '用户名'@'主机名' identified with mysql_native_password by '新密码';

-- 删除用户
drop user '用户名'@'主机名';
```

> 主机名：`%` 代表可以在任意主机访问该数据库

示例：

```mysql
-- 创建用户itcast，只能够在当前主机localhost访问，密码123456；
create user 'itcast'@'localhost' identified  by '123456';

-- 创建用户heima，可以在任意主机访问该数据库，密码123456；
create user 'heima'@'%' identified by '123456';

-- 修改用户heima，的访问密码为1234；
alter user 'heima'@'%' identified with mysql_native_password by '1234';

-- 删除itcast@localhost用户
drop user 'itcast'@'localhost';
```

#### 权限控制

| 权限                 | 说明         |
| :----------------- | ---------- |
| all,all privileges | 所有权限       |
| select             | 查询数据       |
| insert             | 插入数据       |
| update             | 修改数据       |
| delete             | 删除数据       |
| alter              | 修改表        |
| drop               | 删除数据库/表/视图 |
| create             | 创建数据库/表    |

```mysql
-- 查询权限
show grants for '用户名'@'主机名';

-- 授予权限
grant 权限列表 on 数据库名.表名 to '用户名'@'主机名';

-- 撤销权限
revoke 权限列表 on 数据库名.表名 from '用户名'@'主机名';
```

> 注意：多个权限之间，使用逗号分隔；授权时，数据库名和表名可以使用 `*` 进行通配，代表所有

示例：

```mysql
grant all on test.* to 'heima'@'%';
revoke all on test.* from 'heima'@'%';
```

## 四、约束

### 概念

| 约束   | 关键字           | 描述                           |
| ---- | ------------- | ---------------------------- |
| 非空约束 | `not null`    | 限制该字段的值不能为null               |
| 唯一约束 | `unique`      | 保证该字段的所有数据都是唯一、不重复的          |
| 主键约束 | `primary key` | 主键是一行数据的唯一标识，要求非空且唯一         |
| 默认约束 | `default`     | 保存数据时，如果未指定该字段的值，则采用默认值      |
| 检查约束 | `check`       | 保证字段值满足某一个条件                 |
| 外键约束 | `foreign key` | 用来让两张表的数据之间建立连接，保证数据的一致性和完整性 |

示例建表语句：

```mysql
create table user(
    id int primary key auto_increment comment '主键',
    name varchar(50) not null unique comment '姓名',
    age int check ( age>0 and age<=120 ) comment '年龄',
    status char(1) default '1' comment '状态',
    gender char(1) comment '性别'
) comment '用户表';
```

### 外键约束

#### 语法

```mysql
-- 创建表时指定外键
create table 表名(
    字段名 数据类型,
    ...,
    [constraint] 外键名称 foreign key (外键字段名) references 主表(主表列名)
);

-- 建表后添加外键
alter table 表名 add constraint 外键名称 foreign key (外键字段名) references 主表(主表列名);

-- 删除外键
alter table 表名 drop foreign key 外键名称;
```

>外键名称：`fk_从表_主表`，例 `fk_emp_dept`

#### 外键行为

| 行为          | 说明                                       |
| ----------- | ---------------------------------------- |
| restrict    | 当父表中修改对应记录时，首先检查该记录是否有对应外键，如果有则不允许修改（默认） |
| no action   | MySQL中等同RESTRICT                         |
| cascade     | 当父表中修改对应记录时，同步修改子表中关联记录                  |
| set null    | 当父表删除对应记录，子表外键字段置为null（要求子表该字段允许null）    |
| set default | 父表变更时，子表外键设置默认值（InnoDB不支持）               |

示例：

```mysql
-- 准备主表dept
create table dept(
    id int auto_increment comment 'ID' primary key,
    name varchar(50) not null comment '部门名称'
) comment '部门表';
insert into dept(id, name) values (1,'研发部'),(2,'市场部'),(3,'财务部'),(4,'销售部');

-- 子表employee
create table employee(
    id int auto_increment comment 'ID' primary key,
    name varchar(50) not null comment '姓名',
    age int comment '年龄',
    job varchar(20) comment '职位',
    salary int comment '薪资',
    entrydate date comment '入职时间',
    managerid int comment '直属领导ID',
    dept_id int comment '部门ID'
) comment '员工表';

-- 添加外键（出现蓝色小钥匙）  
alter table employee add constraint fk_emp_dept_id foreign key (dept_id) references dept(id);
 
-- 删除外键
alter table employee drop foreign key fk_emp_dept_id;

-- 主表修改时，子表也修改，级联操作
alter table employee add constraint fk_emp_dept_id foreign key (dept_id) references dept(id) on update cascade on delete cascade;
```

>注意：不能直接修改已有外键的行为，必须先删除已有外键，再重新创建

## 五、多表查询

### 多表关系

1. **一对多**：在多的一方建立外键，指向一的一方主键
2. **多对多**：建立第三张中间表，中间表至少包含两个外键，分别关联两张表主键
3. **一对一**：在任意一方加入外键，关联另外一方主键，并且设置外键唯一

> 多对多建表示例：学生、课程、学生课程中间表

```mysql
-- 学生表
create table student(
    id int auto_increment primary key comment '主键ID',
    name varchar(10) comment '姓名',
    no varchar(10) comment '学号'
) comment '学生表';
insert into student values (null,'戴名',2000101),(null,'谢逊',2000102);

-- 课程表
create table course(
    id int auto_increment primary key comment '主键ID',
    name varchar(10) comment '课程名称'
) comment '课程表';
insert into course values (null,'Java'),(null,'PHP'),(null,'MySQL'),(null,'Hadoop');

-- 中间表
create table student_course(
    id int auto_increment comment '主键' primary key,
    studentid int not null comment '学生ID',
    courseid int not null comment '课程ID',
    constraint fk_sc_student foreign key (studentid) references student(id),
    constraint fk_sc_course foreign key (courseid) references course(id)
) comment '学生课程中间表';
insert into student_course values (null,1,1),(null,1,2),(null,1,3),(null,2,2);
```

### 多表查询概述

笛卡尔积：`select * from employee,dept;`，会得到两张表所有记录组合，**需要加条件消除无效笛卡尔积**

```mysql
-- 多表查询
select * from employee,dept;#笛卡尔积
select * from employee,dept where dept_id=dept.id;
```

### 多表查询分类

#### 1. 连接查询

- **内连接**：查询A、B交集部分数据

```mysql
-- 隐式内连接
select 字段列表 from 表1,表2 where 连接条件;

-- 显式内连接（推荐）
select 字段列表 from 表1 [inner] join 表2 on 连接条件;
```

- **外连接**

- 左外连接：查询左表所有数据，以及两张表交集部分数据

```mysql
select 字段列表 from 表1 left [outer] join 表2 on 条件;
```

 - 右外连接：查询右表所有数据，以及两张表交集部分数据

```mysql
select 字段列表 from 表1 right [outer] join 表2 on 条件;
```

- **自连接**：当前表与自身连接查询，必须使用表别名

```mysql
select 字段列表 from 表A 别名A join 表A 别名B on 条件;
```

#### 2. 子查询

子查询：查询语句中嵌套select语句，也叫内查询；外层查询为主查询。

- **标量子查询**：子查询返回**单个值**（数字、字符串、日期），常用 `> < >= <= = <>`
- **列子查询**：返回结果是一列（多行），常用 `in , not in , any , some , all`
- **表子查询**：返回结果多行多列，放在`in`中

#### 3. 联合查询 union

将多次查询结果合并，`union`自动去重；`union all`直接拼接（不去重）

> 多张表查询的**列数必须一致，字段类型保持匹配，列顺序也必须对应**

```mysql
select 字段列表 from 表A
union [all]
select 字段列表 from 表B;
```

### 多表查询示例

```mysql
## 隐式内连接  
select employee.name,dept.name from employee,dept where employee.dept_id=dept.id;  
select  e.name,d.name from employee e,dept d where e.dept_id=d.id;##别名简化  
  
## 显式内连接  
select e.name,d.name from employee e inner join dept d on e.dept_id=d.id;  
  
## 左外连接  
select e.* from employee e left outer join dept d on e.dept_id = d.id;  
  
## 右外连接

## 自连接  
select a.name,b.name from employee a ,employee b where a.managerid=b.id;  
select a.name '员工',b.name '领导' from employee a left outer join employee b on a.managerid=b.id;  
  
## 联合查询(两次查询结果直接粘在一起）  
select * from employee where salary<20000  
union all  
select * from employee where age<35;  
  
## 联合查询(两次查询结果去重后接在一起）  
select * from employee where salary<20000  
union  
select * from employee where age<35;  
  
##子查询(标量子查询）  
##查询研发部所有员工信息

##列子查询

##行子查询  
##查询与逍遥的职位及领导相同的员工信息  
select * from employee where (job,managerid) = (select job,managerid from employee where name='逍遥');  
  
##表子查询  
##查询与逍遥，小赵职位和领导相同的员工信息  
select * from employee where (job,managerid) in (select job,managerid from employee where name='逍遥'or name='小赵');  
  
##查询入职是2000-01-01之后的员工信息及其部门信息  
select * from employee where entrydate>'2000-01-01';##这是一张表

```

## 六、事务

### 概念

事务是一组操作的集合，它是一个不可分割的工作单元。事务会把所有操作作为一个整体，向系统提交或撤销操作请求，要么同时成功，要么同时失败。

### 事务操作

1. 查看事务提交方式

```mysql
select @@autocommit;
```

`@@autocommit=1`自动提交；`@@autocommit=0`手动提交

2. 事务操作

```mysql
-- 开启事务
start transaction;  ## 或 begin
-- 提交事务
commit;
-- 回滚事务
rollback;
```

示例转账事务：

```mysql
create table account(
    id int auto_increment primary key comment '主键ID',
    name varchar(10) comment '姓名',
    money int comment '余额'
) comment '账户表';
insert into account(name, money) values ('张三',2000),('李四',2000);

-- 开启事务（转账：张三给李四转 1000 元）
start transaction;
update account set money = money - 1000 where name='张三';
update account set money = money + 1000 where name='李四';
commit;      -- 两条都成功则提交
-- 任一步失败则回滚，保证余额不丢失
rollback;
```

### 事务四大特性 ACID

1. **原子性（Atomicity）**：事务是不可分割的最小单元，事务内操作要么全部成功，要么全部失败。
2. **一致性（Consistency）**：事务完成前后，数据保持一致。
3. **隔离性（Isolation）**：多个事务并发执行，事务之间相互独立。
4. **持久性（Durability）**：事务提交后，数据永久保存到数据库。

### 并发事务问题

| 问题    | 说明                                 |
| ----- | ---------------------------------- |
| 脏读    | 一个事务读到另一个事务未提交的数据                  |
| 不可重复读 | 同一事务内，两次读取同一数据，期间别的事务修改并提交，两次结果不一致 |
| 幻读    | 一个事务查询数据时，另一个事务插入新数据，导致前后读取行数不一致   |

### 事务隔离级别

| 隔离级别                          | 性能  | 脏读   | 不可重复读 | 幻读   |
| ----------------------------- | --- | ---- | ----- | ---- |
| Read uncommitted（读未提交）        | 最高  | 可能发生 | 可能发生  | 可能发生 |
| Read committed（读已提交）          | 高   | 避免   | 可能发生  | 可能发生 |
| Repeatable read（可重复读，MySQL默认） | 中   | 避免   | 避免    | 可能发生 |
| Serializable（串行化）             | 低   | 避免   | 避免    | 避免   |

```mysql
-- 查看隔离级别
select @@transaction_isolation;
-- 设置会话隔离级别
set session transaction isolation level read committed;
```

> 隔离级别越高，性能越低。

## 七、索引

### 概念

索引是帮助 MySQL **高效获取数据**的**有序**数据结构（默认 B+Tree）。没有索引时查询需要全表扫描，有了索引可以大幅减少扫描行数。

> 本质：索引是一种数据结构，用「空间换时间」。

### 分类

| 分类维度 | 类型                             | 说明                        |
| ---- | ------------------------------ | ------------------------- |
| 功能   | 主键索引 primary key                | 主键自动创建，唯一且非空                |
|      | 唯一索引 unique                    | 值唯一，允许 NULL                |
|      | 普通索引 index / key               | 最基础，无唯一性要求                 |
|      | 全文索引 fulltext                  | 用于大文本全文检索                 |
|      | 组合索引（联合索引）                     | 多个字段组成一个索引，遵循最左前缀法则        |
| 结构   | B+Tree 索引（默认）                  | InnoDB/MyISAM 默认           |
|      | Hash 索引                        | Memory 引擎，只支持等值查询          |

### 语法

```mysql
-- 创建索引
create [unique | fulltext] index 索引名 on 表名(字段1,字段2,...);

-- 查看索引
show index from 表名;

-- 删除索引
drop index 索引名 on 表名;
```

### 最左前缀法则（组合索引重点）

组合索引 `index idx_emp(name, age, status)` 建立后，查询要**从最左列开始且不跳过中间列**才能命中：

```mysql
-- 命中
where name = '张三';
where name = '张三' and age = 20;
where name = '张三' and age = 20 and status = '1';
-- name 跳过则失效（仅 age / status）
where age = 20;            -- 失效
where name = '张三' and status = '1'; -- 只有 name 生效，status 不生效
```

### 回表 与 覆盖索引

- **回表**：通过二级索引（非主键索引）查到主键值，再回主键索引（聚簇索引）查完整行的过程。
- **覆盖索引**：查询的字段都在索引里，无需回表，性能最好。

```mysql
-- 只查索引内字段，覆盖索引，不回表
select id, name from emp where name = '张三';
```

### 索引失效场景

1. 违反最左前缀法则（组合索引跳过/不以最左列开头）
2. 对索引列做**函数、运算、类型隐式转换**：`where year(entrydate)=2026`、`where age+1=21`、`where phone=138...`（字符串列比较数字）
3. `like '%xx'` 以通配符开头（`'xx%'` 可以走索引）
4. 使用 `or` 连接，且存在非索引列
5. 数据量很小、或查询结果占比过大时优化器可能选择全表扫描

### 设计原则

1. 对**查询频繁、区分度高**的字段建索引；性别等区分度低的字段建索引收益小
2. 控制单表索引数量，索引过多会拖慢写入
3. 尽量用**覆盖索引、联合索引**代替多个单列索引

## 八、视图

视图是一张**虚拟表**，本质是保存的一条 select 查询语句，不真正存储数据，数据来自基表。

```mysql
-- 创建视图
create [or replace] view 视图名 as select 语句;
-- 查询视图（用法同表）
select * from 视图名;
-- 修改视图
alter view 视图名 as 新select语句;
-- 删除视图
drop view [if exists] 视图名;
```

作用：
1. 简化复杂查询，封装经常使用的 SQL
2. 只暴露部分字段，隐藏敏感列（数据安全）
3. 视图中的更新有诸多限制，一般把视图当作「查询」使用

## 九、存储引擎

存储引擎是 MySQL 中**存储数据、建立索引、更新查询数据的实现方式**，表级别可选。

```mysql
-- 查看支持的引擎
show engines;
-- 建表指定引擎
create table 表名(...) engine = InnoDB;
```

| 对比项  | InnoDB（默认）            | MyISAM          | Memory     |
| ---- | --------------------- | --------------- | ---------- |
| 事务   | 支持                    | 不支持             | 不支持        |
| 锁    | 行级锁（默认）               | 表级锁             | 表级锁        |
| 外键   | 支持                    | 不支持             | 不支持        |
| 存储结构 | 表 + 索引在一个 .ibd 文件（聚集）  | 数据 .MYD + 索引 .MYI | 内存         |
| 崩溃恢复 | 支持（redo log）          | 不支持             | 不支持        |
| 适用场景 | 绝大多数业务表，强调事务/并发        | 只读为主、不需要事务        | 临时表、缓存     |

> InnoDB 主键索引是**聚簇索引**，数据就存在叶子节点；二级索引叶子存的是主键值（因此会回表）。
