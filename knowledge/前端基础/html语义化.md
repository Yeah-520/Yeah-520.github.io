# HTML 语义化

合理使用语义化标签，能让页面结构更清晰，也更利于搜索引擎与无障碍工具理解内容。

## 常用语义标签

- `<header>`：页头或区块头
- `<nav>`：导航
- `<main>`：页面主要内容
- `<article>`：独立的完整内容块
- `<section>`：有主题的内容分区
- `<footer>`：页脚或区块尾

## 一个示例

```html
<main>
  <article>
    <h1>文章标题</h1>
    <p>这是正文内容。</p>
  </article>
</main>
```

> 语义化不是目的，清晰的文档结构才是。
